## 🎯 Key Requirements

The specification defines:
- **21 offline conditions** (T1–T21) for reproducible evaluation
- **2 live conditions** (L1–L2) for LLM-based interaction
- **Evaluation framework** for assessing router behavior and skill output
- **Comparison capability** for version-to-version analysis
